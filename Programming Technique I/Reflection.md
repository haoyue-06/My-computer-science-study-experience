# SECJ1013 PROGRAMMING TECHNIQUE I
Programming Technique I is a course that equips the students with theory and practice on problem solvinf techniques by using the structured approach. The course covers the following topics, which are **preprocessor directives**, **constants and variables**, **data types**,**input and output statements**, **control structures（sequential, selection and loop）**, **built-in and user-defined functions**, **single and two dimensional arrays**, **file operations**, **pointers**, and **structured data types**. In this course, the studnet required to use C++ programming language to develop the program to solve the problems.<br><br>
